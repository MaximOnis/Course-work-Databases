
# Система обліку магазину гаджетів

Десктопний застосунок для автоматизації обліку товарів, замовлень, постачальників, клієнтів і продавців магазину гаджетів.

Програма розроблена на Python з використанням бібліотеки CustomTkinter для створення графічного інтерфейсу та MySQL для зберігання й обробки даних.

## Можливості

- Перегляд, додавання, редагування та видалення товарів.
- Управління замовленнями та інформацією про їх оплату.
- Облік постачальників і клієнтів.
- Управління даними про продавців.
- Пошук і сортування записів.
- Формування та експорт звітів у форматі Excel.

## Технології

- Python — основна мова програмування. 
- CustomTkinter — створення графічного інтерфейсу.
- MySQL — реляційна база даних.
- MySQL Connector — взаємодія з базою даних.
- Pandas — обробка та експорт даних.

## База даних

Для роботи застосунку використовується локальна база даних MySQL під назвою store. Вона містить таблиці для зберігання інформації про товари, замовлення, постачальників, клієнтів і продавців.
