# Gadget Store Accounting System

A desktop application for automating the tracking of inventory, orders, suppliers, customers, and salespeople at a gadget store.

The program is developed in Python using the CustomTkinter library to create the graphical user interface and MySQL for data storage and processing.

## Features

- View, add, edit, and delete products.
- Manage orders and payment information.
- Track suppliers and customers.
- Manage salesperson data.
- Search and sort records.
- Generate and export reports in Excel format.

## Technologies

- Python — primary programming language.
- CustomTkinter — graphical user interface development.
- MySQL — relational database.
- MySQL Connector — database interaction.
- Pandas — data processing and export.

## Database

The application uses a local MySQL database named “store.” It contains tables for storing information about products, orders, suppliers, customers, and salespeople.
